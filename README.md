# Form Writer

使用 Rust 编写的终端交互式表单工具，以“运动员报名表”为示例，提供文本输入、单选、多选和时间段编辑组件。通过键盘完成填写，并将当前表单数据保存为本地 JSON 文件。

## 功能

- **文本输入**：支持中文、光标移动、插入和删除，以及必填项和自定义校验。
- **单选与多选**：使用方向键浏览选项、空格选择，支持必选和最少选择数量限制。
- **时间段编辑**：按位输入数字或使用方向键调整时间，校验时间范围和时长。
- **交互界面**：显示填写状态，支持重新编辑、跳转到下一未完成项和表单滚动显示。
- **本地保存**：确认退出时，将已完成字段及其状态写入带时间戳的 JSON 文件。

## 快速开始

### 环境要求

- Rust 工具链与 Cargo，编译器需支持 Rust 2021 edition。
- 支持中文显示、光标控制和交互式键盘输入的终端。
- 首次构建需要联网下载依赖。

### 克隆并运行

```sh
git clone https://github.com/SUNNYsyy2005/form_writer.git
cd form_writer
cargo run --locked
```

程序会直接进入“运动员报名表”界面。请在交互式终端中运行。

### 构建发布版本

```sh
cargo build --release --locked
```

生成的程序名为 `form`：

- Windows：`target\release\form.exe`
- Linux / macOS：`target/release/form`

检查项目是否可以编译：

```sh
cargo check --locked
```

## 示例表单

| 字段 | 组件 | 规则或选项 |
| --- | --- | --- |
| 姓名 | 文本输入 | 必填，不能仅包含空白字符 |
| 学号 | 文本输入 | 必填，11 位数字 |
| 院系 | 单选 | 特立书院、睿信书院、精工书院 |
| 特长技能 | 多选 | 至少选择 1 项：编程、绘画、写作、演讲、唱歌、运动、摄影、设计 |
| 勇气值 | 单选 | 1–10 |
| 可参与运动时间 | 时间段 | `HH:MM-HH:MM`，例如 `14:00-16:30` |
| 是否需要高强度训练 | 单选 | 是、否 |
| 备注 | 文本输入 | 可选 |

时间段要求小时为 `00–23`、分钟为 `00–59`，结束时间晚于开始时间，总时长不超过 6 小时；不支持跨午夜时间段。

## 操作说明

### 浏览表单

| 按键 | 操作 |
| --- | --- |
| `↑` / `↓` | 切换当前字段 |
| `Enter` | 编辑当前字段，也可重新编辑已完成字段 |
| `Tab` | 跳转到下一未完成字段 |
| `Esc` | 打开退出确认，`Y` 确认保存并退出，`N` 或 `Esc` 返回表单 |

### 编辑字段

| 字段类型 | 操作 |
| --- | --- |
| 文本 | 直接输入；`←` / `→` 移动光标，`Home` / `End` 移至首尾，`Backspace` / `Delete` 删除 |
| 单选 | `↑` / `↓` 浏览，空格选择或取消选择，`Enter` 确认 |
| 多选 | `↑` / `↓` 浏览，空格切换选中状态，`Enter` 确认 |
| 时间段 | `←` / `→` 移动编辑位置，`↑` / `↓` 调整数值，也可直接输入数字 |

按 `Enter` 校验并完成当前字段，随后自动移至下一字段。必选的单选项尚未选择时，按 `Enter` 会选中当前光标所在选项；示例中的多选项未选择时也会自动选中当前选项。

填写完成后，在浏览状态按 `Esc`，再按 `Y` 保存退出。若正在编辑字段，请先按 `Enter` 完成编辑；可选备注也可以留空后按 `Enter` 确认。

## 数据保存

文件保存在**启动程序时的工作目录**，命名格式为：

```text
form_data_YYYYMMDD_HHMMSS.json
```

例如，使用项目根目录下的 `cargo run --locked` 启动，文件就保存在项目根目录。保存需要该目录具有写入权限。

当前导出包含以下内容：

- `title`：表单标题。
- `items`：字段列表的调试格式字符串。每个字段记录 `prompt`、`type`、`value` 和 `completed`，各值均为字符串。

只有按 `Enter` 确认完成的字段才会导出其值；其他字段的 `value` 为空字符串，`completed` 为 `"false"`。允许保存尚未全部填写完成的表单。

## 项目结构

```text
.
├── Cargo.toml             # 包信息与依赖
├── Cargo.lock             # 依赖版本锁定
└── src/
    ├── main.rs            # 示例表单配置与程序入口
    ├── error.rs           # 错误类型
    ├── models.rs          # 院系、时间、时间段与报名数据模型
    ├── input/             # 表单组件接口与实现
    │   ├── mod.rs         # FormItem 接口与 AnyFormItem 包装
    │   ├── text_input.rs
    │   ├── single_choice.rs
    │   ├── multiple_choice.rs
    │   └── time_input.rs
    └── form/              # 表单状态、布局、渲染、交互与保存
        ├── mod.rs
        ├── types.rs
        ├── core.rs
        ├── display.rs
        ├── render.rs
        ├── components.rs
        ├── edit.rs
        ├── handlers.rs
        └── save.rs
```

主要依赖：`crossterm` 处理终端交互，`serde` / `serde_json` 处理序列化，`chrono` 生成时间戳，`unicode-width` 计算中文等字符的显示宽度。

## 自定义表单

在 `src/main.rs` 的 `process_form()` 中修改标题、字段和选项，通过 `Form::add_item()` 添加由 `AnyFormItem` 包装的组件。文本校验可通过 `TextInput::new()` 的第三个参数传入；多选项的最少选择数量通过 `MultipleChoice::new()` 的第四个参数设置。

调整字段顺序或返回类型时，需要同步修改 `main.rs` 中结果提取的索引和 `downcast_ref` 类型。时间范围校验位于 `src/models.rs`，导出格式位于 `src/form/save.rs`。

## 当前限制

- 当前主循环通过退出确认触发保存，尚未提供独立的“提交表单”入口，也没有读取 JSON 恢复填写的功能。
- `items` 当前以字符串保存；如需供其他程序直接读取字段，应先调整为结构化 JSON 数组。
- 编辑状态下的 `Esc` 返回流程尚不完善，建议使用 `Enter` 完成当前字段后再退出。
- 界面需要足够的终端宽度和高度；显示不全时可放大终端窗口。
